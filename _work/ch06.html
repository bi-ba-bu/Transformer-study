点积：给两张清单打分

案例走到哪了 「它」要判断该看谁。这一章先算它和「老鼠」的匹配分： Q它 [2,0,4,0] · K老鼠 [1,0,1,0] = 6； 和「小猫」只有 2。所以「老鼠」更相关。
说人话 「它」举着一张需求清单，每个词也举着一张自我说明。 两张清单逐项对齐、相乘、再加总，分越高说明越对得上。 点积就是这张“给清单打分”的动作，没有别的魔法。
这一章要解决什么 搞懂点积怎么算，以及它为什么能衡量“两个向量有多相关”。 这是整个注意力机制的地基。

先算一遍，再看道理

两个向量，对应位置相乘，然后全部加起来：

a · b = a₁b₁ + a₂b₂ + … + aₙbₙ

拿案例里的两个向量算：

Q它 = [2, 0, 4, 0]　　K老鼠 = [1, 0, 1, 0]
Q·K = 2×1 + 0×0 + 4×1 + 0×0 = 6

结果是一个数，不是向量。这一点很重要： 点积把两个向量压成一个“匹配分”。

为什么它代表“相似”

点积有一个等价的几何写法：

a · b = |a| |b| cos θ
// θ 是两个向量的夹角

也就是说：点积 = 两个长度相乘，再乘上夹角的余弦。 cos θ 的规律是：

夹角 θcos θ点积含义
0°1最大正值方向完全一致
60°0.5正值大致同向
90°00垂直，方向无关
120°−0.5负值大致反向
180°−1最大负值方向完全相反

所以点积的符号能区分三种情况：同向（正）、垂直（0）、反向（负）。 注意力需要的正是这个带符号的“合不合拍”。

案例手算：它到底更像谁

Q它 = [2, 0, 4, 0]

// 和老鼠
K老鼠 = [1, 0, 1, 0]　→　点积 = 2 + 4 = 6
|Q| = √(2²+4²) = √20 ≈ 4.472
|K| = √(1²+1²) = √2 ≈ 1.414
cos θ = 6 / (4.472×1.414) = 6 / 6.325 ≈ 0.949

// 和小猫
K小猫 = [1, 0, 0, 0]　→　点积 = 2
cos θ = 2 / (4.472×1) ≈ 0.447

「它」和「老鼠」的余弦相似度约 0.95，和「小猫」只有 0.45。 所以第 16 章 softmax 之后，「老鼠」拿到 70.2% 的权重，不是随便编的。

为什么用乘法，不用减法

「比较两个向量」直觉上该用减法：相减取绝对值，越小越像。 但减法只能回答“差多远”，回答不了“方向合不合”。

a = [1, 1]　　b = [1, −1]

// 点积：每一维的贡献带符号，可以正负抵消
1×1 + 1×(−1) = 1 − 1 = 0　→ 整体无关

// 距离：每一维的贡献永远为正，无法抵消
(1−1)² + (1−(−1))² = 0 + 4 = 4

减法把符号抹掉了，所以它看不出“第一维其实完全吻合”。 注意力需要区分同向、垂直、反向三档，点积正好给得出这三档。

投影：点积的物理图像

「K 在 Q 方向上的投影」可以想成正午太阳照下来，杆子在地上的影子。 Q 是地面上的方向，K 是一根斜着的杆子；影子越长，K 朝着 Q 方向的分量越多。

夹角越小　→　影子越长　→　点积越大
垂直　　　→　影子缩成一个点　→　点积 = 0
反向　　　→　影子落在反方向　→　点积为负

下面这个动画把这件事画出来了。青色是 Q，粉色是 K，紫色那段是 K 在 Q 方向上的投影。

点积 = 投影长度 × Q 的长度
旋转 K K 的长度

把“K 的长度”从 1 拖到 1.8。点积变大了，但 cos θ 一点没变。 这说明点积同时混入了方向和长度两个因素。

常见误解：点积大就一定相似 不一定。长度一大，点积也会大，哪怕方向完全没变。 要纯比较方向，应该看 cos θ = (a·b)/(|a||b|)。 注意力里之所以可以直接用点积，是因为 Q/K 都是线性层输出，尺度由模型控制； 而第 18 章的 /√d 处理的是维度带来的方差膨胀，不是“把长度归一化”。

768 维看不见，为什么还能信

这里要分清两件事，很多教程会把它们混成一句：

// 方向
两个随机向量在高维里几乎垂直　→　cos θ ≈ 0

// 大小
如果每个分量是均值 0、方差 1 的随机数
点积的标准差 = √d　→　d=768 时约 27.7，不是 0

“几乎垂直”说的是方向，不是点积等于 0。 所以第 16 章的原始分数会有正有负、绝对值不小；除以 √d 之后，标准差才回到 1 左右。

一句话记住 点积 = 对应位置相乘再加总 = 方向一致性（带符号）× 两个长度。 它回答的是“你朝我这边走了多少”，不是“你每个数和我像不像”。
