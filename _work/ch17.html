加权求和：注意力真正“取走”的东西

案例走到哪了 「它」的权重是 [0.095, 0.035, 0.702, 0.035, 0.035, 0.064, 0.035]。 这一章用这些权重混合 7 个 V，得到「它」的新表示 [0.13, 0.05, 0.73, 0.04]。
说人话 权重是“取多少”的百分比。给「老鼠」70.2%，就从「老鼠」的 V 里取七成； 给「小猫」9.5%，就取不到一成。把所有取到的内容按比例加起来， 就是「它」这一轮吸收到的上下文。
这一章要解决什么 上一章只算出了权重，还什么都没取走。这一章用权重混合 V，注意力公式就完整了。

完整公式

Attention(Q, K, V) = softmax( Q·Kᵀ / √dk ) · V

拆开只有三件事：

  1. Q·Kᵀ：算每个词对每个词的匹配分
  2. softmax(...)：把每行分数变成分配比例
  3. ... · V：按比例把各词的 V 混合起来

手算一遍：它取走了什么

承接上一章的权重，7 个词的 V 是：

V小猫 = [1, 0, 0, 0]
V追　 = [0, 1, 0, 0]
V老鼠 = [0, 0, 1, 0]
V，　 = [0, 0, 0, 0]
V因为 = [0, 0, 0, 1]
V它　 = [0.5, 0, 0.5, 0]
V饿了 = [0, 0.5, 0, 1]
输出 = 0.095×V小猫 + 0.035×V追 + 0.702×V老鼠
     + 0.035×V， + 0.035×V因为 + 0.064×V它 + 0.035×V饿了

第 1 维：0.095×1 + 0.064×0.5 = 0.127
第 2 维：0.035×1 + 0.035×0.5 = 0.0525
第 3 维：0.702×1 + 0.064×0.5 = 0.734
第 4 维：0.035×1 = 0.035

输出 ≈ [0.13, 0.05, 0.73, 0.04]

第三维最大，因为「老鼠」的 V 主要落在第三维，而「它」又把 70.2% 的权重给了「老鼠」。 这就是“输出主要取走了老鼠的内容”的具体含义。

权重 × V 的加权混合

形状怎么变

权重 [7,7] × V [7,4] → 输出 [7,4]

每个 token 的输出是一个固定 4 维向量，和序列长度 n 无关； 但整体形状仍然是 [n,4]，第一维就是 token 数。 不要把它记成“输出和 n 无关”——准确说法是“每个 token 的表示维度固定”。

一句话记住 权重决定“取多少”，V 决定“取什么”。加权求和 = 按比例把所有词的内容混成当前词的新表示。
常见误解：注意力一定很稀疏 实际模型里，很多头确实会把权重集中在少数位置，但不是定理。 有的头看得很散，有的头几乎平均分配。不要用“稀疏”去解释所有注意力图。
一个容易忽略的点 这一步对所有位置同时算，因为矩阵乘法天然并行。 不像 RNN 必须等前一个位置算完才能算下一个，这也是 Transformer 能跑得快的原因之一。
