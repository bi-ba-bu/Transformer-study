# Transformer 动画教程 · 从导数到自注意力

一份**面向零基础**的中文交互式教程，从「导数到底在算什么」一路推到 `Attention(Q,K,V) = softmax(QKᵀ/√d)·V`。

零外部依赖，纯原生 Canvas 手绘动画，**断网也能用**。

## 快速开始

直接双击 `index.html`，用 Chrome / Edge 打开即可。

```
无需安装 · 无需联网 · 无需构建
```

## 这份教程解决什么问题

很多教程卡人的原因不是 Transformer 难，而是**前面的数学被跳过了**——一上来就是那行公式，中间每个符号都不认识。

这份教程的原则是：**每一个符号出现之前，先把它单独讲清楚。** 不假设你记得什么，甚至不假设你写过代码。

| | 内容 |
|---|---|
| **章节** | 29 章（00 引导 + 01–27 正文 + 28 符号速查） |
| **动画** | 25 个可交互场景，可暂停、可拖参数 |
| **符号** | 52 个，每个都有读法 + 白话解释，正文可点击跳转 |
| **自测** | 12 道题，点选项即时判分 + 解析 |

## 章节地图

### 第一部分 · 数学地基（00–14）

| 章 | 主题 | 核心结论 |
|---|---|---|
| 01 | 导数 | 导数就是切线斜率，不是神秘公式 |
| 02 | 链式法则 | 深度网络能训练，全靠「局部导数乘起来」 |
| 03 | 梯度下降 | 沿负梯度下山；学习率超过 `2/λmax` 必发散 |
| 04 | 交叉熵 | `loss = −ln(正确答案的概率)`；越错罚得越狠 |
| 05 | 向量与长度 | `\|a\| = √(各分量平方和)` |
| 06 | 点积 | 点积 = 相似度。**这是注意力的起点** |
| 07 | 矩阵 | 矩阵是对空间的一次揉捏；行列式 = 面积缩放倍数 |
| 08 | 矩阵乘法与转置 | 内维必须相等；`[n,dk]×[dk,n] → [n,n]`，这就是那个 ᵀ |
| 09 | softmax | exp → 求和 → 相除，三步 |
| 10 | 温度 | T 小更确定，T 大更随机 |
| 11 | 从文字到向量 | 查表 = 乘 one-hot，embedding 是可学习参数 |
| 12 | 词向量的意义 | 距离近 = 用法相似，是训练涌现的 |
| 13 | 位置编码 | 注意力不分先后，必须额外注入位置 |
| 14 | 神经元 | 没有非线性，堆多深都等于一层 |

### 第二部分 · 注意力核心（15–20）

| 章 | 主题 | 核心结论 |
|---|---|---|
| 15 | Q / K / V | 用三套权重把「匹配特征」和「传递内容」分开 |
| 16 | 注意力分数 | n×n 关系矩阵，**按行**做 softmax |
| 17 | 加权求和 V | 输出维度 = V 维度，与序列长度无关 |
| 18 | 为什么除 √d | 点积标准差 ∝ √d；不缩放 softmax 饱和 → 梯度消失 |
| 19 | 多头注意力 | 每头 d/h 维，Concat 后仍 d 维 |
| 20 | 因果掩码 | 设成 −∞ 而不是 0，因为 e⁰=1 仍有份量 |

## 时间紧的捷径

**只有 30 分钟**，只想知道公式为什么这么写：

```
06 点积 → 08 转置 → 15 Q/K/V → 16 分数 → 17 加权求和 → 18 除√d
```

**有 50 分钟**，想抓住整体骨架：

```
03 梯度下降 → 04 交叉熵 → 06 点积 → 08 转置 → 09 softmax
→ 15 Q/K/V → 16 分数 → 17 加权求和 → 21 残差 → 24 完整前向
```

## 符号速查：点一下就跳去解释

正文里每个数学符号都可点击（青色下划虚线下划线），点一下跳到第 28 章对应卡片，看完点「↑ 回到正文刚才的位置」原地返回。

每张卡片说清三件事：**符号**、**怎么念**、**什么意思**。

> 数学符号最大的障碍不是「看不懂」，而是**念不出来**。念不出来就没法在脑子里过一遍。所以每张卡片第一行就是读法。

## 数字都是实算的，不是编的

| 数字 | 出处 | 可验证方式 |
|---|---|---|
| 发散阈值 0.481 | 第 03 章 | Hessian 最大特征值 4.155，`2/4.155 = 0.481` |
| 波长 6.28 / 62.8 / 628 / 6283 | 第 13 章 | `2π / (1/10000^(2i/8))`，i=0..3 |
| FFN 占 66.7% | 第 23 章 | `8d²/(4d²+8d²) = 2/3` |
| 12 层 d=768 ≈ 123M | 第 24 章 | `12×(12×768²) + 50000×768`，对标 GPT-2 small 的 124M |

## 实现说明

- 全部动画由原生 Canvas 2D 手绘，DPR 自适应。
- 25 个场景只在滚动到视口内时才渲染（`IntersectionObserver`），不拖慢页面。
- 手机/窄屏下目录自动隐藏，画布高度自适应。
- **几何类场景强制 x/y 等比例**：否则「垂直的投影」会画成斜线、「单位圆」会画成椭圆、「旋转 45°」会变成旋转+拉伸。函数曲线图则刻意保持不等比（教科书惯例）。

### 想加一个新符号

1. 在 `glossary.js` 的 `SYMS` 数组里加一条 `{ k, s, r, g, t, d }`（k 是 id 后缀、s 是符号、r 是读法、g 是分组、d 是解释）。
2. 在 `PATTERNS` 里加一行 `['正文里的写法', 'k']`，正文就会自动变成可点击的。
3. 保存刷新即可。

> **两个刻意的取舍（改的时候别改回去）**
> 1. `→` 和 `×` 故意不做成链接——它们在正文出现 170+ 次，全加链接会让页面看起来全是虚线，干扰主要符号。
> 2. 符号跳转不用平滑滚动——全站 CSS 的 `scroll-behavior: smooth` 会让连续 `scrollTo` 互相取消，实测表现为「点了完全没反应」，所以统一改成瞬时定位。
