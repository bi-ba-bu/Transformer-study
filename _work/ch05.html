向量：一串数，也是一个箭头

案例走到哪了 第 04 章用 loss 衡量错得多重，而真正被调的是模型里的一串串数。 这一章拿起「老鼠」的 4 维向量 [0.8, 0.2, 0.9, 0.1]，先算它的长度约 1.225。
说人话 输入法内部不存“老鼠”这两个字，而是给每个词存一串数字，表示它有哪些特征。 这一章讲这串数字怎么量长短、怎么把长度抹掉只留方向。 下一章判断两个词像不像，就要用到这里的长度。 先把长度算对，后面比较“老鼠”和“小猫”谁更接近时，才不会把长短误当成相似。
这一章要解决什么 搞懂“向量”是什么，以及它的长度怎么算。 下一章点积公式里会出现 |a||b|，那就是两个向量的长度。

两种看法，同一串数

程序员的看法：向量就是一串数。 比如老鼠的向量是 [0.8, 0.2, 0.9, 0.1]，四个数，所以是 4 维。

几何的看法：向量是空间里的一个箭头，从原点指向某个点。 二维时能画出来，四维就画不出来了，但加减、求长度这些规则一样。

a = [3, 2]　→　从原点出发，往右 3、往上 2 的箭头

这个教学模型用 4 维，是为了能手算。真实模型常见 768 维甚至几千维， 图示仍然只在二维上画，因为规则不变，只是数字更多。

长度：勾股定理多用几次

箭头有多长？二维时用勾股定理。[3, 2] 往右 3、往上 2， 长度是斜边：

|a| = √(3² + 2²) = √13 ≈ 3.606

到了四维，勾股定理只是多用几次：每个分量的平方加起来，再开根号。

|a| = √(a₁² + a₂² + … + aₙ²)

记号 |a| 读作“a 的模”或“a 的长度”。 它量的是整个箭头，不是某一个分量。

单位向量：只留方向

两个向量长度不同时，直接比方向会受长度干扰：长的那根更容易让点积变大。 办法是把长度统一成 1，只留下方向。

单位向量 = a / |a|

就是把每个分量都除以长度。[3, 2] 的长度是 3.606， 单位向量是 [3/3.606, 2/3.606] = [0.832, 0.555]。

下一章会看到：点积除以两个长度，剩下的就是纯方向上的相似度。 这里的除法，就是为那一步做准备。

向量的分量、长度、单位向量
a₁ a₂

手算一遍：老鼠向量

老鼠的向量是 v = [0.8, 0.2, 0.9, 0.1]。 先把四个分量分别平方：

0.8² = 0.64
0.2² = 0.04
0.9² = 0.81
0.1² = 0.01

平方和 = 0.64 + 0.04 + 0.81 + 0.01 = 1.50
|v| = √1.50 ≈ 1.225

注意 0.9 是最大的分量，但长度不是 0.9，而是 1.225。 长度把四个方向上的贡献都算进去了。

把每个分量除以 1.225，得到单位向量：

0.8 / 1.225 ≈ 0.653
0.2 / 1.225 ≈ 0.163
0.9 / 1.225 ≈ 0.735
0.1 / 1.225 ≈ 0.082

单位向量 ≈ [0.653, 0.163, 0.735, 0.082]

验算长度：0.653² + 0.163² + 0.735² + 0.082² ≈ 0.9999， 开根号约等于 1。

回到箭头：原来那根箭头长度 1.225，除以自己的长度后， 方向没变，长度变成了 1。这就是“只留方向”的意思。

常见误解 向量的大小和某个分量的大小不是一回事。 [100, 0] 的第二个分量是 0，但它的长度是 100，是一根很长的箭头。 判断相似度不能只盯一个分量，要看整体。
小结 向量 = 一串数 = 一个箭头。长度 |a| = √(各分量平方和)。 老鼠向量 [0.8, 0.2, 0.9, 0.1] 的长度约 1.225； 除以长度得到单位向量，方向不变，长度变成 1。
