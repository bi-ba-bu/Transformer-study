位置编码：让注意力知道谁在前

案例走到哪了 第 12 章说词向量按用法靠近，但向量本身不带位置。 案例的 7 个 token 位置是 0 到 6；「狗咬人」和「人咬狗」用的是同一袋词向量。 在不加因果掩码的设定下，不加位置时，注意力分不出谁在前。
说人话 输入法要知道「追」在「小猫」后面，而不是前面。词向量只说明“是什么”，不说明“排第几”。位置编码给每个位置加一个不同的标记，让后面的注意力有机会区分先后。 位置从 0 数起，这样同一句话换个顺序，向量就会跟着变。
这一章要解决什么 看清“没有位置会丢什么”，以及正弦编码怎么用几对快慢不同的波，给 7 个位置各做一枚指纹。 结论：位置编码是加到词向量上的，不是替换词向量。

先把条件说清：什么时候顺序会丢

“注意力对顺序无感”只在一个设定下成立：没有位置编码，也没有因果掩码。 在这个设定下，把输入的第 0 行和第 2 行对调，输出只会同样对调行，每一行的内容不变。

因果掩码按位置决定“能看谁”：第 5 位能看 0 到 5，第 6 位能看 0 到 6。 这个集合随位置变化，顺序就参与了计算。所以有掩码时，不能再简单说“无感”。

无位置、无掩码：换行 → 输出跟着换行，信息集合不变
有因果掩码：换行 → “能看谁”的集合变了，结果跟着变

第 20 章会细讲掩码。这里先记住：位置信息的缺失，是“无位置 + 无掩码”这个组合下的问题。

为什么这会伤到语言

「狗咬人」和「人咬狗」词相同，谁对谁做什么却相反。 纯注意力能算出“狗和咬有关”，但分不出主客。

并行是它的优点：7 个位置可以同时算，不必像 RNN 那样一个接一个。 代价是顺序没有被表达，位置编码就是补这张票。

正弦编码：给每个位置一枚指纹

原始论文给第 pos 个位置生成一个向量，偶数维放 sin，奇数维放 cos，频率随维度递减：

PE(pos, 2i)   = sin( pos / 100002i/d )
PE(pos, 2i+1) = cos( pos / 100002i/d )

d = 4 时只有两对频率：维度 0/1 的分母是 1，维度 2/3 的分母是 100。 快的那一对管近处，慢的那一对管远处。

PE(pos, 0) = sin(pos)     PE(pos, 1) = cos(pos)
PE(pos, 2) = sin(pos/100) PE(pos, 3) = cos(pos/100)

把案例的 7 个位置 0 到 6 代进去，得到 7 行、每行 4 个数：

看两对维度的差别：维度 0/1 在相邻位置之间变化很大，维度 2/3 在 0 到 6 内几乎不动。 快针负责分辨近处，慢针负责保留更大范围的顺序。

钟表：为什么多根针能定位

秒针转得快，能分辨秒；时针转得慢，能分辨小时。单独看任何一根都有歧义，合起来才能定位到具体时刻。 位置编码用 d/2 对“针”，转速按几何级数递减。

近处靠快针，远处靠慢针。这就是“低维管近、高维管远”的来源。 它不是随手凑的设计，而是“既要分清相邻、又要覆盖长距离”的自然结果。

多频率正弦波拼成位置指纹

加到词向量上，不是替换

位置编码和词向量维度相同，直接逐元素相加。词义还在，位置也带上了。

输入 = 词向量 + 位置编码

老鼠 [0.8, 0.2, 0.9, 0.1] + PE(2) [0.909, −0.416, 0.020, 0.9998]
≈ [1.709, −0.216, 0.920, 1.100]

加完之后，同一个词在不同位置会得到不同的 4 维表示。 注意力仍然只看向量，但向量里已经混进了“我在第几位”。

局限与 RoPE

正弦编码是固定公式。位置超出训练长度时，慢针会进入模型没见过的读数区间，外推会变差。

RoPE 把位置信息转进 Q 和 K 的点积，目标是更好地表达相对距离。 做法不同，目的仍是同一件事：让模型知道谁在前、谁在后。

常见误解 位置编码不是“替换”词向量，而是加在词向量上。 两者维度相同，逐元素相加；加完仍然是 7 个词、每个词 4 维。

回收：钟表

7 个位置像 7 个时刻，每个时刻由几根转速不同的针给出读数。 位置编码把这组读数加到词向量上，注意力才有机会知道谁在前。

一句话记住 没有位置编码、也没有因果掩码时，注意力分不清顺序；正弦编码用多对快慢不同的波，给每个位置一枚有界的指纹。
