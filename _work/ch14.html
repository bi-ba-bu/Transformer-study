神经元：加权和，再把负数截掉

案例走到哪了 第 13 章给「老鼠」的向量加上了位置标记。这一章让这个 4 维向量过一个小神经元： z = 1.55，ReLU 后仍是 1.55；把偏置从 −1 改成 −3，z 变成 −0.45，输出被截成 0。
说人话 输入法不是只做一次查表。每个词还要经过许多小单元加工。一个神经元先按权重把 4 个数合成 1 个判断分，再把负分截成 0。很多这样的单元并排，才能把“老鼠更像被追的对象”这类模式挑出来。 这一步的输出会交给下一层继续加工。
这一章要解决什么 看清一个神经元只做两步：加权和，过 ReLU。 再回答一个问题：为什么中间要插非线性，不能一路只乘矩阵。

两步：加权和 + ReLU

① z = w₁x₁ + w₂x₂ + w₃x₃ + w₄x₄ + b
② a = ReLU(z) = max(0, z)

第一步就是点积再加偏置：四个输入各乘一个权重，加起来，再加 b。 ReLU 把负数截成 0，正数原样放行。

案例用「老鼠」的向量 x = [0.8, 0.2, 0.9, 0.1]。 取一组教学权重 w = [1.0, −0.5, 2.0, 0.5]，偏置 b = −1.0：

z = 1.0×0.8 − 0.5×0.2 + 2.0×0.9 + 0.5×0.1 − 1.0
  = 0.8 − 0.1 + 1.8 + 0.05 − 1.0 = 1.55

ReLU(1.55) = max(0, 1.55) = 1.55

这组权重是为了手算选的，不是训练出来的真实值。 它只演示“四个数怎么合成一个判断分”。

投票器：权重和偏置各管什么

四个特征像四张选票。权重是“这张票我信几分”，偏置是“我本来倾向赞成还是反对”。

第 3 维拿到 2.0 的权重，贡献 1.8；第 2 维权重是 −0.5，贡献 −0.1，相当于一张反对票。 权重为负，不等于输入为负；它只是把这一维的贡献翻个方向。

偏置 b 更像门槛。b 越大，越容易凑够正分；b 越小，越难被激活。

偏置是门槛

紧接着是 ReLU，z > 0 才通过。把 b 从 −1 改成 −3，其他都不动：

z = 0.8 − 0.1 + 1.8 + 0.05 − 3.0 = −0.45
ReLU(−0.45) = 0

同一个输入，只动偏置，这个单元就从“说话”变成“沉默”。 所以 b 不只是让直线平移，它还决定这个单元的启动门槛。

为什么要有非线性

如果只有加权和，两层叠起来是：

h₂ = W₂(W₁x + b₁) + b₂
  = (W₂W₁)x + (W₂b₁ + b₂)

括号里仍是一个矩阵加一个偏置，等价于一层。 叠 100 层线性层，表达能力仍停在一层，深度没有换来新东西。

ReLU 不能写成一次矩阵乘法：它把整条负半轴压成 0，直线被折弯，违反“原点不动、直线还是直线”。 插入它之后，多层才不能合并成一层。

ReLU([−1, −2]) = [0, 0]
ReLU([1, 2])  = [1, 2]
// 负半轴被压成一个点，线性变换做不到
加权和 → 激活函数
权重 w₁

这和第 23 章的 FFN 有什么关系

FFN 是很多个这样的神经元并排：4 维输入先扩到 16 维，再压回 4 维。 第 23 章会数参数；这里先记住每个单元只做“加权和 + 截负”。

注意力负责搬运信息，FFN 负责逐个词加工信息。 两者交替，才构成一层完整的 Transformer。

ReLU 也有代价 如果某个单元对所有输入都算出负值，它的输出长期是 0，梯度也是 0，就很难再被训练回来。 实际模型会用 GELU、SwiGLU 等更平滑的激活，但“引入非线性”这个目的不变。

回收：投票器

每个神经元是一位投票者：按权重听四个特征，有自己的门槛，最后只把正分传下去。 许多投票者并排，就组成一层 FFN。

一句话记住 神经元 = 加权和 + ReLU。非线性让多层不再等价于一层，深度才有意义。
