LayerNorm：让每个向量回到可控范围

案例走到哪了 第 21 章的直通路把每层输入原样带下去，但多层输出不断相加，向量尺度仍可能漂移。 这一章拿「它」的向量 [0.7, 0.1, 0.8, 0.2] 算一遍：均值 0.45，标准差约 0.304。
说人话 在迷你输入法里，每个 token 的 4 维向量进入下一层前，先把自己的数值调到统一尺度。这样某个维度不会因为数值偏大而压过其他维度，后面的注意力也更容易比较。LayerNorm 是逐个 token 做的，不跨句子，也不依赖 batch 大小。
这一章要解决什么 上一章解决了信号通路，这一章解决数值尺度。 你会看到公式、一次完整手算，以及 Transformer 为什么选 LayerNorm 而不是 BatchNorm。

公式里的五个符号

LayerNorm（层归一化）是在单个 token 的向量内部做标准化的操作。 例如 [0.7, 0.1, 0.8, 0.2] 会被变成 [0.822, -1.151, 1.151, -0.822]。

LayerNorm(x) = γ · (x − μ) / √(σ² + ε) + β
符号是什么作用
μ这个向量所有分量的平均值减掉它，把中心移到 0
σ这个向量所有分量的标准差除掉它，把尺度压到 1
ε一个很小的数，如 1e-5防止除以 0
γ, β两个可学习的参数让模型决定要不要缩放、平移回来

关键在统计范围：μ 和 σ 只来自当前 token 自己的 d 个分量， 不跨 token，也不跨样本。

可以把它想成把不同单位的读数换到同一把尺子上： 刻度统一了，谁大谁小仍看得出来。

一个向量内部的标准化过程

用「它」手算一遍

x = [0.7, 0.1, 0.8, 0.2]，只算当前这个 token 的 4 个分量：

① 均值：μ = (0.7 + 0.1 + 0.8 + 0.2) / 4 = 1.8 / 4 = 0.45

② 各分量减均值：
  0.7 − 0.45 = 0.25
  0.1 − 0.45 = −0.35
  0.8 − 0.45 = 0.35
  0.2 − 0.45 = −0.25

③ 方差：
  (0.25² + 0.35² + 0.35² + 0.25²) / 4
  = (0.0625 + 0.1225 + 0.1225 + 0.0625) / 4
  = 0.37 / 4 = 0.0925
  σ = √0.0925 ≈ 0.304

④ 归一化（忽略 ε）：
  0.25 / 0.304 ≈ 0.822
  −0.35 / 0.304 ≈ −1.151
  0.35 / 0.304 ≈ 1.151
  −0.25 / 0.304 ≈ −0.822

γ = 1、β = 0 时，结果就是 [0.822, -1.151, 1.151, -0.822]。 新均值是 0，新方差是 1。

γ 和 β 让模型可以再把尺度和中心调回需要的范围。 归一化不是终点，而是给后续层一个稳定的起点。

为什么用 LayerNorm 不用 BatchNorm

BatchNormLayerNorm
统计范围 跨样本、同一特征 同一 token、跨特征
依赖 batch 吗 依赖，batch 小时统计量容易偏 不依赖，单个样本内部就算完
变长序列 要处理每个位置的有效样本数 天然支持
推理时 要保存训练时的滑动统计量 直接用当前 token 算，无需额外状态

一句话：LayerNorm 的统计量只依赖当前 token，训练和推理走同一套计算， 变长序列也不用特殊处理。

Pre-LN 与 Post-LN

原始 Transformer 把归一化放在残差相加之后，叫 Post-LN： x = LayerNorm(x + Sublayer(x))。

很多现代实现把它放在子层之前，叫 Pre-LN： x = x + Sublayer(LayerNorm(x))。

Pre-LN 的直通路更干净，深层训练通常更稳；Post-LN 也仍在使用。 选哪种要看具体模型，没有唯一答案。

常见误解 LayerNorm 不是把数值压小。 归一化那一步不改变分量之间的大小顺序：原来是第 3 个分量最大，减均值、除标准差后仍是它最大。 后面的 γ、β 再决定要不要缩放和平移。
